# Mood Atlas

A text-classification research demo by Sumith Reddy, rebuilt from the original mental-health project. Flask serves a responsive website and a real TF-IDF/logistic-regression model. No external AI API key is required.

**Not a diagnostic or safety-assessment tool.** Dataset labels describe categories of text, not a person's condition. Scores are uncalibrated model outputs, not clinical risk probabilities. Do not use this demo for healthcare decisions, crisis triage, employment, insurance, or monitoring people.

## Run locally

Use Python 3.12:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest -v
gunicorn app:app --bind 127.0.0.1:5055 --workers 1 --threads 2
```

Open http://127.0.0.1:5055. Only load the trusted model generated by this project's training script: joblib files can execute code.

## Model card

- Source: the owner's original `Actual_dataset.csv`, 38,217 rows. The owner confirmed permission to use it and deploy a trained model. The dataset's upstream provenance, consent process, and label quality have not been independently verified. Raw text is deliberately not distributed.
- Cleanup: 12 invalid/short rows excluded; normalized exact duplicates collapsed; two conflicting text groups excluded. 38,194 usable unique texts remain. Near-duplicates and posts from the same author may still cross the split.
- Deterministic stratified 80/20 split, seed 42: 30,555 training, 7,639 test examples.
- Lowercase, remove URLs, collapse whitespace. Keep negations. TF-IDF fit on training data only, maximum 40,000 unigram/bigram features, minimum document frequency 2. Logistic regression, 1,000 maximum iterations.
- Test accuracy: 89.23%; macro F1: 89.02%. Majority-class baseline: 39.27%. Full per-class results and confusion matrix are in `metrics.json`.
- These are internal held-out dataset metrics, not evidence of clinical validity or generalization. The suicide-labelled class has 82.90% recall on this test split: errors matter, and a negative result cannot establish safety.
- Rebuild, not a byte-for-byte reproduction of the old notebook: preprocessing, deduplication, deterministic splitting, and reporting were corrected. No test-set hyperparameter search was performed.
- English-only demonstration; subject to dataset bias, sarcasm, context loss, domain shift, and uncertain labels. No clinical or demographic subgroup evaluation has been completed.

To reproduce with an authorized private dataset containing `text` and `label` columns:

```sh
python train.py /private/path/Actual_dataset.csv
python -m unittest -v
```

## Privacy and API

No accounts, cookies, analytics, database, recordings, or intentional storage of submitted text. Requests are processed in server memory. Hosting providers may retain infrastructure metadata. Use fictional, non-identifying examples only. The original application's account file and saved recordings are not included.

- `GET /health`: readiness.
- `POST /api/analyze`: JSON object with `text`, 20–3,000 characters. Returns the three original dataset labels and relative model scores.
- Errors: 400 invalid input; 403 cross-site browser request; 413 oversized body; 422 insufficient vocabulary; 429 demo-wide capacity limit (120 requests/minute/worker). Limit stores timestamps, not IP addresses. Single-worker deployment is intentional. Not a robust abuse-prevention system for a high-traffic service.

## Deploy and rollback

`render.yaml` specifies a free Python web service, one worker and two threads. Build with `pip install -r requirements.txt`; start with the command in that file. No database, credentials, migrations, or paid features required. Verify `/health`, homepage, and a fictional text submission after deployment. Check logs for errors without logging request bodies.

Before release: tests passing; no raw data or credentials in tracked files; verify desktop/mobile layouts and safety copy. If the health endpoint fails, analysis returns 5xx, or incorrect model assets are loaded, roll back to the previous successful Render deploy. For a first deploy, suspend the service and fix locally. No external code review or production monitoring has yet been completed.

To contribute, use a branch, include tests, and preserve privacy and non-diagnostic framing. Do not add dataset posts to examples or bug reports.
